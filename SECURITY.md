# Personal security reporting

This repository and website follow the
[mlaifyxyz personal security reporting policy](https://github.com/mlaifyxyz/.github/blob/main/SECURITY.md).
That is the single canonical policy for repositories owned by `mlaifyxyz`.

The policy explains that these are personal projects I run myself, so security, support, and
coordinated vulnerability disclosure (CVD) under the vulnerability disclosure policy (VDP) are best
effort; there is no bug bounty or paid disclosure program; no payment, rewards, or swag are offered; and a
report does not create an obligation to respond, investigate, fix, publish, credit, or coordinate.

For a credible, confidential vulnerability in this website, use this repository's **Security**
tab and select **Report a vulnerability**. Use a public issue for ordinary site bugs, broken
links, content corrections, and feature requests. Reports sent by email are not processed.

The deployed `matthewd.xyz` and `matthewd.org` sites and this repository are the project-specific
systems in scope.
