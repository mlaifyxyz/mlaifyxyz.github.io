# Earlier public camera disclosures

This is context for the [current IPC-D240W-S evidence](README.md), not a claim that every older CVE affects the tested camera or the supplied MCA50E V3.6.3.1 image. The products, boards, firmware branches and dates differ. The F and N identifiers in this repository are local research labels, not the CVE IDs below.

| Report | What it reported | Coordination record and relevance |
|---|---|---|
| [Bishop Fox, SV3C L-Series HD Camera, 2018](https://www.bishopfox.com/news/2018/10/sv3c-l-series-hd-camera-multiple-vulnerabilities/) ([current advisory URL](https://bishopfox.com/blog/sv3c-l-series-hd-camera-advisory); [NVD CVE-2018-12666](https://nvd.nist.gov/vuln/detail/cve-2018-12666)) | Ten issues in two 2017 SV3C L-Series firmware versions, including hard-coded passwords, authentication, command injection and information disclosure. | The advisory said no fix had been released at publication. This is an earlier reseller/firmware-family warning, not proof of a direct code lineage or an unresolved CVE on my 2026 model. |
| [Willgues, Anpviz IP Camera Vulnerabilities, 2024](https://willgu.es/pages/anpviz-ip-camera-vuln.html) | CVE-2024-35341 through CVE-2024-35344: unauthenticated configuration download, settings changes, arbitrary file read and a shared cryptographic key in the affected V3.2.2.2-and-earlier products. The article also documents a debug/Telnet route. | The researcher describes repeated requests for a patch timeline and little substantive vendor response before disclosure. Its debug/Telnet observation is relevant to my F22 comparison, but I have not treated those four CVEs as assigned to my F findings. |
| [andylee77, Anjvision coordinated disclosure, 2026](https://github.com/andylee77/anjvision-cve-2026) | A public coordination repository lists ten proposed issues in a YSSD-RTMP-H5 firmware family across several brands, including Anpviz. Its list includes debug command injection, ONVIF authentication and unsigned updates. | The repository says the author contacted Anjvision and CERT/CC in May 2026. Its README still labels the CVE IDs pending. Similar issue classes warrant comparison, but its YSSD-RTMP-H5 target is not demonstrated to be the same image or board as my IPC-D240W-S. |

The history is relevant because questions about default authentication, privileged debug access and firmware authenticity had been public before my October 2026 report. It does not establish that Anpviz knew of each F1–F24 defect, intentionally retained it, or failed to cooperate in every case. The 2024 researcher's account describes his own unsuccessful coordination; my [current timeline](README.md#coordinated-vulnerability-disclosure) separately records Anpviz's later technical response and its wrong-board image.
